# 專題進度報告：智慧交通的可信任聯邦學習

報告人：Austen
日期：2026-11-03
程式與完整數據：GitHub `austenjuan2222/UnivProject`（README 有每個實驗的設定與重現指令）

---

## 一、題目與目標

以高速公路局公開的國道 VD（車輛偵測器）每分鐘資料，預測 5／15／30 分鐘後的車速。
每個 VD 當作一個聯邦學習的參與者，**原始資料不離開 VD**，只上傳模型參數；
訓練時加上差分隱私（DP-SGD），並依課程講義的 IoT 架構與 IoT 安全內容，讓系統能抵抗竄改、入侵裝置與斷線，
同時評估放在 Edge 設備與低功耗廣域網路（LPWAN）上的可行性。

## 二、系統架構（對照講義「五個問題」）

| 問題 | 本專題的做法 |
|---|---|
| 感知什麼 | VD 的車速、流量、佔有率，整理成每 5 分鐘一筆（國道 1 號，2024 年 3 月 4 週，8～256 個 VD） |
| 在哪裡算 | Edge：每個 VD 本地訓練；Cloud：伺服器只做聚合 |
| 怎麼連 | 每輪每個 VD 上傳約 6 KB，量化後 0.79 KB；部署時用 TLS |
| 如何變聰明 | 聯邦學習（Flower）＋各 VD 本地微調 |
| 如何保護 | 差分隱私、HMAC／數位簽章、穩健聚合、安全聚合、裝置認證與撤銷 |

## 三、目前完成的工作

### 1. 資料與訓練流程

- 撰寫下載、清理與 5 分鐘聚合程式，挑出資料完整的主線 VD，依時間切分訓練與測試，避免資訊洩漏。
- 用 Flower 建立聯邦學習流程，用 Opacus 做 DP-SGD。
- 發現 Flower 官方範例每輪重新計算隱私預算 ε，會低估實際隱私成本；改成跨輪累計，並和 Opacus 的計算交叉驗證。

### 2. 準確度與隱私的取捨

- 改成「殘差模型」（預測相對於目前車速的變化）後，DP 模型的誤差 2.712 km/h，與無 DP 的 2.743 相當，都優於 naive 基準 2.916。
- 實驗拆開裁剪與雜訊的影響，發現 DP 的代價主要來自梯度裁剪，雜訊幾乎不影響準確度；預測 30 分鐘時 DP 模型反而比無 DP 準。
- 加入時段特徵（sin/cos 編碼）後，在 4 週資料、5 個 seed 都顯著改善（p<0.001），且不增加 ε。
- VD 數從 8 增加到 256 時，聯邦學習的效益變大；保護「整個 VD」的 client-level DP 在 256 個 VD、ε=0.79 時仍比 naive 好 8.8%。

### 3. 依課程講義補強資安（32 個 VD，每組 3 個 seed，並與同版程式的無攻擊對照比較）

| 講義主題 | 威脅 | 我的做法 | 結果 |
|---|---|---|---|
| MAC | 網路上竄改更新 | 每台 VD 獨立金鑰的 HMAC-SHA256，輪次一起簽 | 25% 被竄改時，沒有驗證會輸給 naive；有驗證全部擋下 |
| 防重送 | 重送上一輪的舊訊息 | 同上（輪次簽進訊息） | 舊訊息全部被拒絕 |
| 數位簽章、不可否認 | 假的模型更新、VD 事後否認 | Ed25519 簽章＋稽核紀錄 | 準確度不變，每份只多 64 bytes |
| 攻擊類型：裝置被入侵 | 被入侵的 VD 持有合法金鑰送惡意更新 | 中位數、截尾平均、伺服器端裁剪 | 一般平均誤差暴增到 251 km/h；中位數 2.232，仍贏 naive |
| 入侵偵測 | 多台 VD 串通、每次只偏一點 | 跨輪相似度偵測 | 能找出全部串通的 VD，無攻擊時不誤判 |
| 針對性攻擊 | 讓模型「看不到塞車」 | 另外評估塞車時段的誤差 | 整體誤差只多 0.03～0.19，但塞車時段預測偏快 9 km/h；說明只看整體指標會漏掉攻擊 |
| TLS、RFID 偽造標籤、撤銷 | 竊聽、假裝置、被入侵的裝置 | Flower 部署模式：TLS＋裝置公鑰註冊＋撤銷 | 假裝置、明文連線、被撤銷的裝置都連不上 |
| 機密性（伺服器不可信） | 伺服器偷看單一 VD 的更新 | 安全聚合（X25519 成對遮罩），並支援斷線復原 | 準確度不變；10% 斷線時仍能聚合 |
| 可用性 | VD 斷線 | 伺服器略過沒回應的 VD | 每輪 30% 斷線仍正常完成 |

我也測試了不同防禦之間的極限：串通偵測抓得到「多台同方向偏移」的攻擊，卻完全抓不到「隱藏壅塞」攻擊，因為後者的更新方向和正常 VD 一樣分散。這說明偵測方法要針對攻擊的特徵設計，沒有一種防禦能擋下所有攻擊。

全部防禦同時開啟，並同時面對 3 台入侵、10% 竄改、10% 斷線時，誤差 2.295 km/h，仍比 naive 好 5.5%。

### 4. Edge 資源與 LPWAN

- 量測單台 VD：記憶體峰值 425 MB（其中 365 MB 是 PyTorch／Opacus 框架），每輪訓練 0.16 秒。
- 資安運算成本：簽章與 HMAC 不到訓練時間的 0.1%；安全聚合約 2%，且上傳量加倍。
- 用 Semtech 的 LoRa 空中時間公式估算：不壓縮時訊號差的 VD 每輪需 9.6 小時；量化成 4 位元後降到 1.3 小時，準確度不變。
  台灣 AS923 頻段的單包 400 ms 限制下，訊號差的 VD 較適合改用 NB-IoT。

## 四、目前的限制

- 資料只涵蓋 2024 年 3 月、國道 1 號，需要更長、更多路段的資料驗證。
- 隱私保證是「單筆量測」層級；相鄰時間的資料高度相關，解讀 ε 時要注意。
- 安全聚合為簡化版，尚未實作完整的 SecAgg+；穩健聚合與安全聚合無法同時使用。
- 攻擊實驗為模擬，TLS 部署是在單台電腦上用多個行程模擬多台 VD。
